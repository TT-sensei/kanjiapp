# かんじマスター

小学生向けの漢字練習・確認テストWebアプリです。

漢字を「書いて練習する」ことを中心にしながら、確認テスト、復習、苦手漢字の記録、特訓、学習記録、レベルアップやバッジコレクションなどを組み合わせています。

ブラウザだけで動作するため、学校や家庭のタブレットからそのまま利用できます。

## 公開ページ

[かんじマスターを開く](https://tt-sensei.github.io/kanjiapp/)

## このアプリについて

このアプリは、日本の小学校で学習する漢字を対象に、日々の短い練習と確認を繰り返せるように作った学習支援Webアプリです。

単に漢字を一覧で覚えるのではなく、

1. 漢字を見て書く
2. 書き順を確認する
3. テストで確かめる
4. 間違えた漢字を記録する
5. 苦手な漢字をもう一度練習する
6. できるようになったか再確認する

という学習の流れを作ることを重視しています。

また、学習の継続を支えるために、経験値、レベル、周回、称号、バッジなどの仕組みを取り入れています。

## 主な機能

### 学年別の漢字学習

1年生から6年生まで、学年ごとに漢字を選んで学習できます。

ホーム画面では各学年の進み具合を確認でき、学年ごとの学習状況を切り替えて見ることができます。

漢字データはJavaScriptファイルとして分離されているため、学習する漢字を追加・修正するときにもデータ部分を確認しやすい構成になっています。

### れんしゅう

漢字を実際に書いて練習するためのモードです。

漢字の表示に加えて、書き順のアニメーションを確認できます。

「もう一度書く」「書き順を見る」といった操作を繰り返しながら、漢字の形と書き順を確かめます。

練習した漢字は学習状況として保存されるため、あとから進み具合を確認できます。

### テスト

学習した漢字を使って確認テストを行います。

練習だけで終わらせず、「自分で書けるか」を確認するためのモードです。

テストでは例文を利用した確認も行えるようになっており、漢字そのものだけでなく、実際の言葉の中で読み方や使い方に触れられる構成になっています。

### きょうの10もん

その日の短い学習として取り組める10問のチャレンジです。

まとまった時間が取れないときでも、少しずつ漢字に触れられるようにしています。

クリアするとボーナス経験値を獲得できます。

### ふくしゅう

これまでの学習状況をもとに、復習したい漢字を取り出して学習できます。

一度できた漢字だけを何度も繰り返すのではなく、学習履歴を使って復習につなげることを目的としています。

### とっくん

自分で「もう少し練習したい」と思った漢字を、とっくんフォルダに登録できます。

漢字一覧から複数の漢字を選んで、一括で「とっくん」に登録することもできます。

登録した漢字だけを集めて練習できるため、自分の課題に合わせた学習ができます。

### にがて

テストなどで間違えた漢字や、自分で苦手だと感じる漢字を「にがて」として管理できます。

「にがてテスト」も用意されているため、苦手な漢字を練習するだけでなく、あとからできるようになったか確認できます。

### 学習カルテ

学習の状況を確認できる「がくしゅうカルテ」を用意しています。

練習やテストの履歴、間違いの記録などをもとに、自分がどのように学習してきたかを振り返るための機能です。

### 漢字検索

ホーム画面から漢字を検索できます。

学年を選んで学習するだけでなく、「この漢字を練習したい」という目的から直接探すこともできます。

一覧画面にも検索機能があり、漢字を探しながら特訓・苦手フォルダへの登録を行えます。

### 出題範囲の共有

学習する漢字の範囲を選び、「はんいを共有」する機能があります。

教師や家庭で指定した漢字を、学習する範囲として扱いやすくするための機能です。

### おたのしみバッジ

学習を進めることで、さまざまなバッジやコレクションを集められます。

学習そのものを置き換えるものではなく、継続して取り組むための小さな楽しみとして用意しています。

レベルアップに応じてコレクションが増えていきます。

### レベル・経験値・周回

練習やテストに取り組むことで経験値を獲得し、レベルアップします。

さらに、学年ごとの学習を繰り返し進める「周回」の仕組みもあります。

同じ漢字を一度できたら終わりにするのではなく、何度も触れる機会を作ることを目的としています。

## 学習データについて

学習状況はブラウザのlocalStorageに保存されます。

そのため、サーバー上のアカウントやデータベースを使わずに、端末内で学習記録を管理できます。

主に次のような情報を保存しています。

- 練習の進み具合
- テストの進み具合
- とっくんに登録した漢字
- にがてに登録した漢字
- 間違えた回数
- 学習統計
- レベル・経験値
- 周回状況
- 獲得したバッジなどの状態

ブラウザのデータを消去した場合や、アプリ内の「データリセット」を実行した場合は、これらの学習記録もリセットされます。

学校で複数の端末を使う場合、端末をまたいで学習履歴が自動的に同期される仕組みではありません。

## 対応端末

タブレットでの利用を中心に設計しています。

スマートフォンやPCのブラウザでも利用できますが、学校での学習ではタブレットの画面サイズを基準に操作しやすいUIを設計しています。

横向き・縦向きの画面サイズにも対応しています。

## 技術構成

このアプリは、外部サーバーを必要としない静的Webアプリとして構成しています。

使用している主な技術は以下のとおりです。

- HTML
- CSS
- JavaScript
- localStorage
- GitHub Pages

ビルド環境やバックエンド、データベースは使用していません。

主なファイル構成は次のとおりです。

```
kanjiapp/
├── index.html
├── main.js
├── style.css
├── kanji-data.js
├── title-data.js
├── kanjiExampleData_1.js
├── kanjiExampleData_2.js
├── kanjiExampleData_3.js
├── kanjiExampleData_4.js
├── kanjiExampleData_5.js
├── kanjiExampleData_6.js
├── LICENSE
└── README.md
```

### index.html

アプリ全体の画面構造を定義しています。

ホーム、漢字一覧、練習画面、結果画面、レベルアップ画面、バッジ画面などのUIが含まれています。

### main.js

アプリの中心となるJavaScriptです。

学習モードの切り替え、漢字の出題、練習結果の記録、テスト、復習、とっくん・にがて管理、経験値、レベル、周回、バッジ、学習カルテなどを管理しています。

### style.css

アプリの見た目とレスポンシブ対応を管理しています。

タブレットで大きく押しやすいボタンや、縦画面・横画面でのレイアウト調整などもここで行っています。

### kanji-data.js

学年ごとの漢字データを管理しています。

漢字の追加・修正など、学習内容そのものを変更するときに確認する主要ファイルです。

### kanjiExampleData_1.js ～ kanjiExampleData_6.js

各学年の漢字に関連する例文・用例データを管理しています。

テストなどで、漢字を言葉や文の中で確認するために使用します。

### title-data.js

レベルアップなどで表示する称号・コレクション関連のデータを管理しています。

## 書き順・字体について

本アプリでは漢字の書き順表示などにKanjiVGのデータを利用しています。

ただし、データ上の都合により、一部の漢字で学校で学習する書き順や字体と異なる表示になる場合があります。

そのため、アプリ内でも次の考え方を明記しています。

「学校で習った書き方が最も正しい基準です。」

アプリの判定や書き順表示は学習を補助するための目安として利用してください。

学校の教科書や先生の指導と異なる場合は、学校で学習している内容を優先してください。

## プライバシーについて

このアプリでは、学習履歴をサーバーに送信して管理する仕組みはありません。

学習データは基本的に利用しているブラウザのlocalStorageに保存されます。

ただし、アプリで使用している外部リソースについては、ブラウザから該当するWebリソースへアクセスが発生する場合があります。

## データのリセット

ホーム画面下部の「データリセット」から、学習データを初期化できます。

リセットすると、レベル、経験値、学習履歴、とっくん・にがて登録などの保存データが削除されます。

一度削除した学習履歴は元に戻せないため、必要な場合は注意してください。

## 開発について

このアプリは、実際の学習場面で使いやすいことを意識しながら継続的に改善しています。

特に、

- タブレットで操作しやすいこと
- 漢字を書くことを中心にすること
- 短時間でも取り組めること
- 間違えた漢字を次の学習につなげること
- 「練習して終わり」ではなく、テストで確かめること
- 学習の継続を邪魔しない範囲で楽しさを加えること

を大切にしています。

仕様や画面、学習データの構成は今後変更される場合があります。
